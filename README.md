Objetivo del Proyecto
El propósito de este estudio es realizar un análisis exploratorio y estadístico del comportamiento de uso de los clientes de ConnectaTel, empresa de telecomunicaciones en Latinoamérica. El análisis abarca la información operativa registrada hasta el año 2024 para identificar patrones de consumo, detectar perfiles atípicos y proponer recomendaciones estratégicas orientadas a la optimización de planes y la retención de clientes.
Fuentes de Datos
El análisis se fundamenta en el procesamiento e integración de tres conjuntos de datos (datasets):
plans.csv: Especificaciones comerciales de la oferta de planes (tarifas mensuales, cuotas incluidas de minutos/GB y costes adicionales por exceso de consumo).
users.csv: Registro demográfico y contractual de la base de clientes (edad, ubicación geográfica, fecha de alta, plan suscrito y tasa de cancelación / churn).
usage.csv: Registro transaccional del consumo efectivo de servicios de voz y mensajería por usuario.

Metodología y Alcance
Limpieza y Exploración de Datos (EDA): Identificación de valores nulos, evaluación de tipos de datos y análisis de distribución estadística.
Evaluación de Outliers: Identificación y validación analítica de valores atípicos mediante el rango intercuartílico (IQR), categorizándolos como usuarios de alto consumo (heavy users) para preservar la integridad del modelo.
Segmentación y Profiling: Clasificación de clientes según grupos de edad y niveles de uso (Alto, Medio, Bajo) para caracterizar el valor de la cartera.
Insights de Negocio: Formulación de recomendaciones comerciales basadas en evidencia para la optimización tarifaria y la prevención de fuga de clientes.
Nota aclaratoria: Este proyecto corresponde a un ejercicio práctico desarrollado como parte de un proceso de evaluación en análisis de datos.Los datos utilizados fueron simulados con fines puramente académicos e instruccionales.
